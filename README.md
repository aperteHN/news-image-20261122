Entry for make.fun `news-image-20261122`: "Sum up 22 November's world news in one image."

`main.py` (Python 3, standard library only) draws a one-page newspaper
front page for Sunday 22 November 2026 and writes it to `/output/entry.png`
(or `$MAKEFUN_OUTPUT_DIR/entry.png`). The image is 1024x1024 PNG, drawn
pixel by pixel with a built-in 5x7 bitmap font, and is byte-for-byte
identical on every run.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Stories shown, as reported on 22 November 2026: the COP31 climate talks
